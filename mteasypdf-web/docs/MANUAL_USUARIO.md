# Bienvenido

Bienvenido a **MTEasyPDF Web**.

Este sistema fue desarrollado para facilitar la elaboración de **Memorias Técnicas**, automatizando un proceso que anteriormente se realizaba de forma manual.

Con esta aplicación podrá generar un reporte completo en pocos minutos a partir de la información del proyecto y un archivo ZIP que contenga las evidencias correspondientes.

No es necesario tener conocimientos técnicos para utilizar el sistema.

---

# Objetivo del Sistema

El objetivo principal de MTEasyPDF Web es ayudar al personal de HEMAC a generar Memorias Técnicas de forma rápida, uniforme y con una presentación profesional.

El sistema organiza automáticamente las imágenes, incorpora la información del proyecto y genera un archivo PDF listo para su entrega.

---

# Requisitos

Antes de utilizar el sistema asegúrese de contar con lo siguiente:

* Acceso al sistema MTEasyPDF Web.
* Archivo ZIP con las evidencias del proyecto.
* Imagen de portada (opcional).
* Logotipos institucionales (opcionales).

---

# Pantalla Principal

La pantalla principal está dividida en dos secciones.

## Datos del Proyecto

Aquí deberá capturar la información general de la Memoria Técnica.

Los campos disponibles son:

### Título

Escriba el nombre que tendrá la Memoria Técnica.

Ejemplo:

> Memoria Técnica – Mantenimiento Preventivo

### Información Extra

Este campo es opcional.

Puede utilizarlo para indicar información adicional como:

* Cliente
* Planta
* Área
* Número de servicio
* Folio

### Introducción

Escriba una breve descripción del trabajo realizado.

Esta información aparecerá en las primeras páginas del documento.

### Incluir sección de ubicación

Esta opción permite indicar si el reporte incluirá la sección de ubicación del proyecto.

Generalmente se recomienda mantener esta opción activada.

# Generar la Memoria Técnica

Una vez capturada toda la información:

1. Revise que los datos sean correctos.
2. Verifique que el archivo ZIP sea el correspondiente al proyecto.
3. Presione el botón:

**Generar Memoria Técnica**

Durante el proceso no cierre la ventana del navegador.

---

# Extraer el Archivo ZIP

Una vez descargado el archivo:

1. Localice el archivo ZIP.
2. Haga clic derecho.
3. Seleccione **Extraer todo**.
4. Espere a que finalice la extracción.

No abra el PDF directamente desde el archivo ZIP comprimido.

# Uso de los Hipervínculos

Al final del documento encontrará la sección **Anexos del Proyecto**.

Los enlaces mostrados en color azul permiten abrir directamente la documentación asociada.

Para que funcionen correctamente:

* El archivo PDF debe permanecer dentro de la carpeta generada por el sistema.
* No cambie el nombre de la carpeta.
* No elimine la carpeta **anexos**.

# Recomendaciones

Para obtener mejores resultados:

* Utilice imágenes de buena calidad.
* Verifique que el archivo ZIP corresponda al proyecto correcto.
* No modifique la estructura interna del ZIP.
* Extraiga siempre el archivo antes de abrir el PDF.

---

# Solución de Problemas

## El sistema no genera el reporte

Verifique que haya seleccionado un archivo ZIP válido.

---

## El botón de descarga no aparece

Espere a que finalice el procesamiento.

Si el problema continúa, vuelva a intentar la generación.

---

## Los hipervínculos no funcionan

Asegúrese de haber extraído completamente el archivo ZIP antes de abrir el PDF.

---

## No encuentro los anexos

Los documentos se encuentran dentro de la carpeta **anexos** generada automáticamente.

# Preguntas Frecuentes

### ¿Puedo modificar el PDF generado?

Sí.

Sin embargo, cualquier modificación será responsabilidad del usuario.

---

### ¿Puedo utilizar cualquier archivo ZIP?

No.

Debe contener la estructura de evidencias definida para el proyecto.

---

### ¿Los logotipos son obligatorios?

No.

Son opcionales.

---

### ¿Puedo generar nuevamente el mismo reporte?

Sí.

El sistema permite generar el reporte las veces que sea necesario.
